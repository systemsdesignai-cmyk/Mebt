# MEBT — Prototype PRD v1.0
## Outcome
Demonstrate a self-service administrative navigator for Habesha households in South Africa. Turn fragmented guidance into next actions, records and follow-ups. Not a law firm, official status checker or guarantee of outcomes.
## Users and scope
Adults across citizen, permanent resident, refugee, asylum seeker, visa/permit, expired and unknown/undocumented statuses. Status optional. No employment-rights module. No live legal advice, real authentication, real uploads, payment or notifications in prototype.
## Core journeys
1. Choose English, Amharic or Tigrinya; guest or simulated sign-in; optionally select status and goal. Guest can browse public content; simulated account unlocks demo case features.
2. Home: next action, active cases, due reminders, quick actions. Start a fictional citizenship, permanent residence or asylum/refugee case. Other categories appear as clearly labelled previews.
3. Case: checklist, user-recorded status, blocker selection, suggested next action, timeline, simulated correspondence and follow-up scheduling. Completion reflects checklist only, never official progress.
4. Rights: filter by status; simple language, source/date fields and audio demo controls clearly marked simulated. Do not invent legal requirements; use placeholders marked pending verification.
5. Assistance: browse directory mock entries, filter, preview contact actions and escalation; no real calls or messages. Emergency resources must remain free in future product.
6. Vault: fictional metadata and sample documents only; expiry, search and categories; no file picker or real sensitive data.
7. Notifications: simulated in-app reminders, preferences for push/email/WhatsApp/SMS/calendar; no delivery.
8. Profile: language, accessibility, demo reset, premium preview without checkout.
## Coverage
Nine categories: citizenship, PR, asylum/refugee, complaints, civil documents, rights, business/financial access, visas, emergency protection. Deep demo journeys for first three plus shared follow-up. Other workflows preview only. Free/premium boundaries proposed, no price.
## Acceptance
All core journeys clickable; state survives reload using fictional data only; reset works; guest can browse; no network transmission of user data; no external AI API; no real upload or login; all demo labels visible; responsive 360–1440px; keyboard access and readable contrast; language switching covers core interface with unreviewed translations labelled; no fabricated legal claims; no broken navigation. Provide build and test evidence before sharing.
